# Portfolio 3.0 — Anshuman (ANXHU)

A personal portfolio website built with clean semantic HTML5, Vanilla CSS, and modern interactive JavaScript.

Inspired by the curated aesthetic of [Wall of Portfolios](https://www.wallofportfolios.in/portfolios/ayush-dhibar/) and designed to showcase multidisciplinary craft across:
- **Artificial Intelligence & Systems** (Continuo, Sentinel AI, AI Hedge Fund)
- **3D Design & Blender** (Hard-surface modeling, character armatures, procedural shaders)
- **UI/UX & Product Design** (Design tokens, glassmorphism, cognitive ergonomics)
- **Creative Technology & Graphic Design** (Swiss typography, liquid chrome)

## Key Features

- **Interactive Mode**: Toggle between ultra-fluid motion mode (custom tracking cursor, 3D card tilt, draggable polaroid collage, synthesized Web Audio sound feedback) and lightweight minimal mode.
- **Editorial Typography**: Typographical pairing of *Montaga* serif, *Caveat* script, *Fragment Mono*, and *Inter*.
- **Interactive Case Studies**: Deep-dive modals built with accessible native `<dialog>` overlays.
- **Wall of Portfolios Easter Egg**: Celebratory modal with 3D tilting badge and custom canvas confetti.
- **Live IST Clock**: Real-time Indian Standard Time digital indicator.
- **Pure Vanilla Stack**: Fast, dependency-free load times.

## Setup & Running Locally

Simply open `index.html` in your favorite browser, or serve it with any static server:

```bash
# Using Python
python -m http.server 3000

# Using Node / npx
npx serve .
```
